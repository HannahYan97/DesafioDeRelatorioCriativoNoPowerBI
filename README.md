# Desafio de criação de Relatórios Interativos no Power BI

O desafio consiste em criar 2 páginas de relatórios interativos. Onde na qual foi elaborado o layout dos relatórios
manualmente com criação de botões de navegabilidade, setas de direcionamento e inserção de imagens externas em png.
